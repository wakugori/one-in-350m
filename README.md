# 3億5千万分の1

ランダムなアメリカ人として生まれ、その人生を最後まで生きるブラウザゲーム。「80億分の1（1in8b.life）」のパロディで、公式とは関係ありません。

- 生まれる人は毎回同じです。
- チャーリー・カークらしくない選択を続けたり、歴史の分岐点で選択を誤ったりすると、歴史の修正力によって人生が終わります。
- 死因は図鑑に集まります（ブラウザごとに保存）。

静的な HTML / CSS / JS だけで動きます。`index.html` を開くか、GitHub Pages で配信します。

人物の経歴は公開されている報道と Wikipedia にもとづき、選択肢と台詞は創作です。暴力を肯定する意図はありません。
